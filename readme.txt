این افزونه در فرانت اند هنگام لود سایت درخواست های سایت های خارجی که در هنگام اینترنت ملی باعث کندی سایت میشود را مسدود میکند.

== Description ==

افزونه مسدودکننده سایت‌های خارجی برای وردپرس

این افزونه با استفاده از فرانت اند ریکوئستور درخواست‌های سایت‌های خارجی که هنگام اینترنت ملی باعث کندی سایت می‌شوند را مسدود می‌کند.

**امکانات:**
- مسدودسازی درخواست‌های خارجی
- قابلیت فعال/غیرفعال کردن از پنل مدیریت
- قابلیت شخصی‌سازی لیست دامنه‌های مسدود شده
- به‌روزرسانی خودکار ریکوئستر

== Installation ==

1. پوشه `internet-melli` را در مسیر `wp-content/plugins/` آپلود کنید
2. افزونه را از پنل وردپرس فعال کنید
3. به مسیر «مسدودکننده خارجی» در منوی کناری بروید
4. افزونه را فعال کنید
